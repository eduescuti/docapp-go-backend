Estados

Solo los turnos y las órdenes guardan estado. El de las recetas se calcula y los resultados no tienen.

Turno turnos.estado

Nace pendiente. Lo confirma o rechaza el profesional; lo cancela el paciente. Al pasar la fecha, el confirmado se completa y el pendiente se rechaza solo.

Orden ordenes.estado

Pasa a listo cuando el laboratorio carga el primer resultado, en la misma transacción.

Receta: activa si vigenteHasta >= hoy, si no pasada (calculado, no se guarda).
Resultado: sin estado; el "Nuevo" es solo del frontend.
